# stout (версия для передачи): сборка и перенос на сервер

## Что это

Статический сайт калькулятора: один HTML-файл, JavaScript и CSS. Серверной части нет:
без входа, без базы, без почты, без Telegram, без распознавания, без денег и без 3D.
Сметы хранятся в браузере посетителя, КП выгружается в PDF и Excel прямо на устройстве.

Исходный сайт heatcalc.ru и ветка `main` не меняются. Эта версия собирается из ветки
`claude/stout-peredacha` в папку `dist-peredacha/`.

## Сборка

Из корня ветки:

```
python scripts/build_peredacha.py
python scripts/check_peredacha.py
```

`check_peredacha.py` должен закончиться строкой `ИТОГ: OK`. Он проверяет: нет ли VALTEC,
разбираются ли JS-файлы, все ли локальные файлы на месте, нет ли внешних загрузок, кроме
двух библиотек cdnjs (см. «Что ещё нужно сделать»).

Локальная проверка: `python scripts/serve_dist.py 8090`, затем открыть http://localhost:8090/

## Правила каталога

- Позиции VALTEC удалены полностью: в каталоге, в индексе цен и в доп. прайсе.
- Если у позиции STOUT есть альтернатива ROMMER, альтернатива удалена, остаётся STOUT.
- Позиции других брендов остаются, если STOUT-пары нет.

Ограничение: пара STOUT–ROMMER определяется полем `rommer` в каталоге. ROMMER-позиции без
этого поля, которые по смыслу дублируют STOUT, остаются в каталоге. Такие места можно
перечислить отдельно и решить вручную.

## Что убрано из сборки

- Вход и облако: Supabase, Google, Telegram, Яндекс ID, кабинет, подписки, тарифы.
  Окна входа и панель разработчика скрыты стилем, код не удалялся.
- Вкладки «3. Распознавание», «4. Деньги», «5. 3D», «Почему дешевле».
- Распознавание проектов и планов, акты, цены по объектам (`reprice`), администрирование.
- Запросы к внешним сервисам: ipapi.co, ipinfo.io, cbr-xml-daily.ru, proxy.heatcalc.ru,
  api.qrserver.com (QR теперь рисуется локально), Google Fonts (шрифт Inter заменён на Roboto из `fonts/`).
- Регистрация Service Worker и манифест PWA.
- Блокировка по домену (`allowedHosts`): отключена, сайт открывается с любого адреса.

## Перенос на сервер

Нужен любой веб-сервер для статики. PHP, база данных и исходящие подключения не нужны.

1. Скопировать содержимое `dist-peredacha/` в корень сайта (например, `/var/www/stout/`).
2. Включить HTTPS.
3. Отдавать файлы без кэширования для `index.html`, `app.js`, `catalog.js`,
   `price_index.json` (или с коротким сроком), остальное можно кэшировать.
4. Для nginx пример:

```
server {
    listen 443 ssl;
    server_name stout.example.ru;            # адрес сайта
    root /var/www/stout;
    index index.html;
    charset utf-8;

    location ~* \.(js|css|json|woff2|png|jpg|webp)$ {
        expires 7d;
    }
    location = /index.html {
        add_header Cache-Control "no-cache";
    }
    location / {
        try_files $uri $uri/ =404;
    }
}
```

5. Адрес сайта в мета-тегах (`canonical`, `og:url`) по умолчанию heatcalc.ru. На новом
   сервере заменить на свой адрес в `index.html` и в страницах `oferta.html`, `privacy-policy.html`.

## Что ещё нужно сделать до передачи

1. Библиотеки PDF и Excel (`html2pdf.js` 0.10.1 и `xlsx` 0.18.5) сейчас грузятся с cdnjs.
   Чтобы сайт работал без доступа к cdnjs, их нужно положить в `vendor/` и поменять пути
   в `index.html` (блок `HC_LAZY`). Нужно разрешение на скачивание этих файлов.
2. Шрифт: Inter заменён на Roboto. Если нужен Inter, положить его `woff2` в `fonts/` и
   поменять `fonts/fonts.css`.
3. Проверка в браузере на целевом сервере: смета, вкладка «Монтажные работы», КП в PDF и Excel.
4. Политика конфиденциальности и оферта: проверить реквизиты и адрес сайта.
