# Параллельные сессии Claude: короткая памятка

Полный текст — раздел в корневом `CLAUDE.md`. Здесь только то, что нужно в момент коммита.

1. Пишешь код → свой worktree (`/worktree`), ветка `claude/<имя>` от свежего `origin/main`.
2. **Никогда** `git add -A` / `commit -a`. Только `git add app.js other.js`.
3. Перед пушем `node --check app.js` (одна ошибка кладёт весь калькулятор).
4. Версии `?v=` в `index.html` и `CACHE_NAME` в `sw.js` поднимать **перед слиянием**, только у изменённых файлов.
5. Ветка живёт ≤ дня. После слияния удалить worktree и ветку. В конце одной строкой: влито ли в `main`.
6. Общая папка стоит на `main` и чистая.
7. Правка разделов 1–2 сметы → `node bench/assembly.js`; распознавание → `node bench/project.js …`.
