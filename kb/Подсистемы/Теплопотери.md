# Теплопотери

- Точки входа: `getHouseHeatLoss()` (кВт котла), `getRoomHeatLoss`, `getHouseHeatLossModes` (комфорт / эконом / +5 °C).
- Быстрый режим: `area × h × 37 × region × mat` — см. [[Стандарт 100 Вт на м2]]. Подробный: слои стен `wallLayers`, крыша, пол, остекление.
- База R стены без пирога: `wallBaseR` (R_тр города по [[СП 50.13330]]); квартира осталась на 1,8 (`FLAT_HOUSE_MAT`).
- Вентиляция: V·n·0,34·ΔT, n = 0,35 / 1,0 / 0,25 (рекуператор).
- Пол по грунту — зоны I–IV ([[СНиП 2.04.05-91]]). Наружные двери: `roomExtDoors`, `DOOR_AREA` 2,1, `DOOR_R` 0,7.
- Запас котла `BOILER_RESERVE_K` 1,15 — практика, не норма.
- Температуры помещений: [[ГОСТ 30494-2011]].
- Стенды: `bench/heat_compare.js`, `bench/design_room_temps.js`.
- Расширенный текст: `calculation_logic.md` в корне.
