# Бренды и каталог

- `app.state.brandMode`: `'stout'` (по умолчанию) или `'rommer'` (подставляет `.rommer`). `ANALOG_MAP` — замены «Аналог».
- Позиция: `{ id, name, price, brand?, availability, price_date, rommer? }`. Новая: массив `catalog.*` → при необходимости `rommer` → фото `img/<id>.jpg` → `price_date`.
- Цены видит только PRO (`price-blur` у остальных).
- `catalog.js` грузится 750 КБ: `?v=` поднимать только при реальной правке.
- Паспортные данные радиаторов брать у завода (SEBINO/TONALE/ANTEPRIMA — GLOBAL, ROMMER RST — буклет ROMMER); цифру без указанного ΔT не брать.
