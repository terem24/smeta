# Стыковка обвязки котельной (НР/ВР)

Каждый резьбовой стык — пара «наружная ↔ внутренняя/накидная гайка» одного размера.

1. Правка разделов 1–2 сметы → `node bench/assembly.js`; все объекты «резьба сходится». Остаток допустим только от позиций «нет данных о концах».
2. Порт прибора — только по паспорту, с `src`. Не знаем НР/ВР → тип `U`, не угадывать.
3. Переход трубы выбирать по тому, во что он вкручивается, а не по диаметру трубы (кран ВР/ВР → переход на НР; ВР/НР → на ВР). Нет пары — ВР меньшей резьбы и ниппель/футорка.
4. Порты бойлеров/котлов — в каталоге: `ports`, `fem`, `dhwValve`/`dhwPorts`. Схема `buildSchemeConfig` читает то же.
5. Открытые вопросы к ТЕРЕМ: резьба крана SMS-0912, комплект RMS-3210 (см. память).

Скилл `run-benches` прогоняет всё это перед выкладкой. См. [[Смета и render]].
