# Распознавание комплекта листов проекта (PDF)

Цепочка: `RecognizeFiles.projectSheets` → `fromProjectSet` → модель читает помещения → `RecognizeProject.fitExplication` → окна → отопление/сантехника/вентиляция → примечания.

- Что есть текстом/линиями — читать программой; модель только для остального (тип прибора по картинке, трапы на выносках).
- «В какой комнате» — геометрия (`recognize_geo.js`), не зрение. Раскладка по чертежу — только если место нашлось у каждой подписи.
- Одна раковина — одна; смеситель и прибор — одна штука.
- Из чертежа → зелёное (`r.eng.src[поле] = 'pdf'`); ручная правка снимает отметку.
- Примечания к помещению — только факты.
- Подбор: соответствие проекту, не цена. Бренд **STOUT → ROMMER → остальные**, внутри — дешевле. Нет подходящего → плашка «Нет полного соответствия проекту», молча не подменять. `app.pierRadPick`.
- Правки монтажника пишутся в архив (`result[].edits`) — раз в неделю искать повторяющиеся ошибки.
- Стенд: `node bench/project.js bench/projects/<имя>.json` (Хвойная 3: 127 из 132 на 25.09).
